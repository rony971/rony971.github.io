Choisis une date dans le mois affiché. Les dépenses d'une catégorie prévue sont suivies dans leur enveloppe ; seul leur dépassement réduit davantage le reste prévisionnel. Les dépenses « Hors budget » diminuent directement le reste estimé. Les entrées d'argent l'augmentent.

🧸 Mes dernières opérations

💡 Mode d'emploi

1. Quand ta paie arrive, coche « salaire arrivé ».

2. Ajuste les enveloppes : cantine, courses, impôts, loisirs, épargne…

3. Ajoute tes achats au fil de l'eau, notamment les sorties et le gacha.

4. Si tu paies le billet en 3 fois, enregistre chaque échéance dans « Hors budget » ou crée une enveloppe dédiée pour ce mois.

5. Exporte régulièrement tes données en JSON pour garder une sauvegarde.

🔒 Tes données restent enregistrées dans ce navigateur, sur cet appareil grâce au stockage local. Rien n'est envoyé en ligne tant que tu ne te connectes pas avec « Se connecter » ; ensuite, une copie lisible par ton seul compte est gardée sur Supabase. Si tu effaces les données du navigateur, utilise ton export JSON pour les récupérer.
